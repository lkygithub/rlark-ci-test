# Governance

## Overview

RLark is an open-source project under the [RLinf](https://github.com/RLinf) organization. The project is governed by the core maintainers with input from the community.

## Decision Making

- **Technical decisions**: Made by maintainers through code review and consensus on pull requests and issues
- **Feature proposals**: Discussed via GitHub Issues with community input before implementation
- **Breaking changes**: Require maintainer consensus and a deprecation notice where applicable

## Roles

### Maintainers

Maintainers are listed in [MAINTAINERS.md](MAINTAINERS.md). They have write access to the repository and are responsible for:

- Code review and merge
- Release management
- Community health and moderation

### Contributors

Anyone who contributes code, documentation, or participates in discussions is a contributor. Contributors are expected to follow the [Code of Conduct](CODE_OF_CONDUCT.md).

### Community

All community members are welcome to participate in discussions, report issues, and suggest features via GitHub Issues.

## Release Process

- Releases follow [Semantic Versioning](https://semver.org/)
- Release notes are published with each release
- Currently in **Alpha** stage (v0.1.x) — APIs and features may change
