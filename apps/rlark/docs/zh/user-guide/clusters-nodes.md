# 集群与节点

**集群**页面汇总已经纳管的数据面及其可用 Worker 节点；**节点**页面展示资源类型、可调度状态、健康状态、地理位置、GPU 或具身设备型号、运行中的 Worker 与容量信息。

控制面节点及其他非 Worker 节点不计入可调度资源。遇到集群离线、节点被封锁或关键资源标注缺失时，请联系平台管理员。

## 通过 UI

业务平台 → 集群或节点。使用类型、状态和地理位置筛选资源；点击集群或节点进入详情，查看容量、健康状态和正在运行的 Worker。

## API equivalent

查询 Cluster 与 Node 资源。字段和过滤参数参见 [API 参考](../api/reference.md)。
